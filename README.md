# Spectrum-Heap-Parser
Writes spectrum (from mzxrules) output in a cleaner format

run `python mm_heap.py d.txt` for example where `d.txt` is the text file you copy and pasted the spectrum output into. Just be careful you paste according to the format shown in `d.txt` and `j.txt`.

Be sure to use the `t ll` command in spectrum to toggle the linked list nodes being displayed. Be sure you do `game mm u0` or `game mm j1` for english or jp1.1 (I forget if it is e.g. `game mm u0` or `game mmu0` but just try them both worst-case)
